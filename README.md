# Автошкола «Старт»

Современный лендинг автошколы в Воронеже. Создан по мотивам типичных сайтов автошкол (включая структуру и контент в духе avtoshkola-voronezh.ru / jaguar-avtoshkola и аналогов).

## Что есть на сайте

- **Hero** — главный экран с призывом и бесплатным пробным занятием
- **Категории** — A, B, C и переподготовка
- **Преимущества** — 6 ключевых плюсов
- **Как проходит обучение** — 4 шага
- **Тарифы** — Базовый / Стандарт / Комфорт
- **Отзывы** учеников
- **Форма заявки** (с имитацией отправки)
- **Контакты** и футер
- Адаптивная вёрстка (мобильные / планшет / десктоп)
- Мобильное меню

## Технологии

- Чистый HTML5 + CSS3 + Vanilla JS
- Шрифт Inter (Google Fonts)
- Без фреймворков — легко развернуть где угодно

## Как открыть локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/usolcevev/Avtoshkola.git
   cd Avtoshkola
   ```
2. Откройте `index.html` в браузере  
   или поднимите простой сервер:
   ```bash
   npx serve .
   # или
   python -m http.server 8000
   ```
